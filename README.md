# 🔗 SlugForge

A lightweight Python CLI tool to generate SEO-friendly URL slugs from text.

## Features

- Lowercase conversion
- Remove special characters and emojis
- Replace spaces with hyphens
- Clean repeated hyphens
- Beginner-friendly

## Run

```bash
python main.py
```

## Example

Input:
```
My First AI Project 🚀
```

Output:
```
my-first-ai-project
```
